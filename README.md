# 🧠 DeepCoder

> Your local AI coding assistant in the terminal — powered by Ollama + DeepSeek Coder, with long-context memory.

---

## 🚀 Features

- ✨ Conversational coding assistant
- 📁 Understands your local project context via `CLAUDE.md`
- 🧠 Long-context memory across multiple turns
- ⚙️ Runs fully offline with [Ollama](https://ollama.com/)
- 🔥 Based on open-source models like `deepseek-coder`

---

## 📦 Installation

1. **Install Ollama** (if you haven’t already):  
   https://ollama.com/download

2. **Install the model you want to use**:

```bash
ollama run deepseek-coder
